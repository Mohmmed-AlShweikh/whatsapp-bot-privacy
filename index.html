n8ntestbot Privacy Policy

Mohammed AlShweikh operates n8ntestbot, a WhatsApp bot that sends an automated reply to incoming text messages.

Data we process and why

When you message the bot, Meta's WhatsApp Cloud API delivers message information to our n8n workflow. This may include your WhatsApp phone number, message text, message identifier, timestamp and profile name. The workflow uses your number to send the reply via WhatsApp and processes the incoming message to identify it as a text message.

Processing and retention

Meta processes messages to deliver them through WhatsApp. The n8n server processes incoming events and sends replies through Meta's API. Message data may appear in n8n execution logs, which are used to check delivery and troubleshoot errors. How long these logs remain available depends on the server's retention settings.

Privacy questions and deletion

To ask a privacy question or request deletion of data we control, email engmohammedalshweikh@gmail.com with the subject “n8ntestbot data deletion.” Include the WhatsApp number used and, if available, the approximate date of your interaction so we can locate the relevant records.
